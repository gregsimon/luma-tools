    A small sound workshop

    Open or drop a sound. Select a useful part, shape it, then drag the highlighted selection down onto any slot card (or choose a slot and Add to slot). Dragging sideways inside the selection starts a new one; Control-drag picks up the selection from anywhere in the waveform.

    Normalize adjusts the selected peak level. The low-pass gate makes a short, darkening tail; Make hit applies it and crops in one step. Undo also restores clearing and slot replacements.

    Pitch changes always use retained source audio. Apply pitch keeps a slot change; editor pitch is kept when you Add to slot. Preview alone never changes a ROM.

    Save project keeps source audio, applied edits, selections and slot pitches for later editing. Export bank ZIP contains the prepared sounds. Export ROM and Program PicoROM use applied slot bytes. Unapplied fade and slot-pitch previews are excluded.

    Keyboard: Space plays the focused editor, LPG, or slot. Keys 1–8 audition the bank when you are not typing or adjusting a control. Command-Z / Ctrl-Z undoes an edit. Escape stops playback or cancels a drag.

    Noon calibration: this review profile uses 12,908 samples per second, estimated from a 440 Hz reference sounding approximately B3 at noon. It is an approximate setting for the tested module; the documented nominal reference is 23,000 Hz. Luma Preview preserves the nonlinear knob sweep and is a listening approximation.

    The app processes locally. PicoROM access always requires a separate action. Bank loading supports 128 KB and either half of a 256 KB image.
